# outline2pptx

A Python tool that builds PowerPoint slide decks from a Markdown outline or from a topic.

## Prerequisites

- Python 3.10 or newer
- A server with an OpenAI-compatible API and a text model, only needed for `--topic`
- LibreOffice, only needed for `--preview`

## Installation

```bash
pip install outline2pptx
```
